## Introduction

Le plugin WooCommerce Singpay Gateway est une extension WordPress conçue pour intégrer parfaitement la solution de paiement Singpay à votre boutique en ligne WooCommerce. Ce plugin vous permet d'accepter différents modes de paiement, facilitant ainsi la finalisation des achats de vos clients.

## Caractéristiques

- **Intégration facile** : S'intègre parfaitement à WooCommerce.
- **Options de paiement multiples** : Offre une variété de méthodes de paiement.
- **Transactions sécurisées** : Offre un environnement de traitement des paiements sécurisé.
- **Convivialité** : Simple à installer et à configurer.
- **Prise en charge des blocs WooCommerce** : L'extension est compatible avec les blocs WooCommerce.
- **Compatibilité avec les tables de commandes personnalisées** : L'extension est compatible avec les tables de commandes personnalisées WooCommerce.
- **Compatibilité avec l'éditeur de blocs de produits** : L'extension est compatible avec l'éditeur de blocs de produits WooCommerce.

## Moyens de paiement

- Paiement mobile (Airtel Money)
- Paiement mobile (Moov Money)
- PayPal
- Maviance

## Dependences

- **WordPress :** Une installation WordPress fonctionnelle.
- **WooCommerce :** Le plugin WooCommerce doit être installé et activé.

## Compatibilite

- **WordPress :** 6.3 ou supérieur
- **WooCommerce :** 8.6 ou supérieur
- **PHP :** 7.4 ou supérieur (testé jusqu'à la version 8.3)

## Installation

1. **Télécharger** : Téléchargez le plugin depuis la source officielle ou le répertoire des plugins WordPress.
2. **Télécharger** : Dans votre panneau d'administration WordPress, allez dans « Plugins » -> « Ajouter » -> « Télécharger le plugin ». Téléchargez le fichier zip du plugin.
3. **Activer** : Après le téléchargement, activez le plugin.
4. **Paramètres** : Allez dans WooCommerce -> Paramètres -> Paiements et recherchez « Singpay Gateway » pour le configurer.

## Singpay Credentials

Pour utiliser l'extension WooCommerce Singpay Gateway, vous devez obtenir les identifiants spécifiques de votre compte Singpay. Ces identifiants sont :
- **ID WALLET**
- **CLIENT ID**
- **CLIENT SECRET**

1. Après avoir activé l'extension, accédez à « WooCommerce > Paramètres > Paiements ».
2. Recherchez « Singpay Gateway » et cliquez sur « Gérer ».
3. Renseignez les informations requises.
4. Enregistrez.
